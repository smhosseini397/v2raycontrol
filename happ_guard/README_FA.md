# Happ Guard — نمونه اولیه اندروید

این برنامه برای هماهنگ‌کردن دو گوشی شخصی طراحی شده است. وقتی گوشی دوم دکمه «این گوشی مالک اتصال شود» را می‌زند، سرور واسط مالکیت را به گوشی دوم می‌دهد؛ گوشی قبلی در heartbeat بعدی فرمان قطع می‌گیرد و Happ Guard فرمان قطع را به Happ می‌فرستد.

## وضعیت این خروجی
- سورس اندروید و workflow ساخت خودکار APK آماده شده است.
- **APK در این محیط کامپایل نشده است**؛ Android SDK و Gradle نصب نیستند و دسترسی دانلود ابزارهای گوگل نیز در دسترس نبود.
- فرمان HAPP از URI اختصاصی `happ://disconnect_without_ui` استفاده می‌کند. عمداً از `toggle` استفاده نشده تا اگر تونل از قبل خاموش باشد، اشتباهاً روشن نشود.
- رفتار قطع باید با نسخه HAPP نصب‌شده روی گوشی واقعی آزمایش شود؛ اگر URI در آن نسخه پاسخ ندهد، مسیر Accessibility تلاش می‌کند دکمه قطع را پیدا کند.

## راه‌اندازی سرور
1. پوشه `server` را با ساختار موجود در `happguard/` روی هاست HTTPS آپلود کنید.
2. آدرس پیش‌فرض برنامه `https://farshkashanco.com/happguard/guard.php` است.
3. کلید سرور در `server/guard.php` تعریف شده و در نسخه شخصی برنامه نیز پیش‌فرض شده است. این کلید را عمومی نکنید؛ کلید داخل APK قابل استخراج است و فقط برای استفاده شخصی مناسب است.
4. پوشه `server/data` باید برای PHP قابل نوشتن باشد. حفاظت `web.config` و `.htaccess` را حفظ کنید.

## گرفتن APK از GitHub Actions
1. فایل ZIP پروژه را در یک مخزن خصوصی GitHub آپلود و Extract کنید؛ محتویات پوشه پروژه باید در ریشه مخزن قرار بگیرند.
2. به تب **Actions** بروید و workflow با نام **Build Happ Guard APK** را اجرا کنید (یا یک push انجام دهید).
3. پس از اتمام موفق، artifact با نام `happ-guard-debug-apk` را دانلود کنید؛ داخل آن `app-debug.apk` قرار دارد.
4. APK را روی هر دو گوشی نصب کنید. این خروجی debug است و برای انتشار عمومی/Play Store امضا نشده است.

## راه‌اندازی روی دو گوشی
1. روی هر دو گوشی Happ Guard را نصب کنید.
2. آدرس API و کلید یکسان را بررسی و ذخیره کنید.
3. در تنظیمات اندروید، سرویس Accessibility برنامه Happ Guard را فعال کنید.
4. محدودیت مصرف باتری Happ Guard را بردارید و اجازه اجرای پس‌زمینه بدهید.
5. روی هر دو گوشی «شروع پایش این گوشی» را بزنید.
6. روی گوشی اول «این گوشی مالک اتصال شود» را بزنید و HAPP را وصل کنید.
7. روی گوشی دوم «این گوشی مالک اتصال شود» را بزنید؛ گوشی اول باید در چند ثانیه فرمان قطع بگیرد.

## محدودیت‌ها و تست
- گوشی قبلی باید روشن، آنلاین و سرویس پایش Happ Guard آن فعال باشد.
- این برنامه اتصال سمت سرور V2Ray را قطع نمی‌کند؛ فقط تونل محلی HAPP را روی گوشی قبلی خاموش می‌کند.
- اگر اندروید اجرای پس‌زمینه را متوقف کند، یا HAPP فرمان قطع را نپذیرد، قطع خودکار تضمین نمی‌شود.
- تا وقتی قطع واقعی روی هر دو گوشی آزمایش نشده، این نمونه را راه تضمینی جلوگیری از بلاک‌شدن حساب تلقی نکنید.
