## فایل سرور آماده
این پوشه را با همین ساختار در پوشه ریشه سایت (همان جایی که فایل‌هایی مثل `signal.php` قرار دارند) داخل `happguard/` قرار بده:
- `guard.php`
- پوشه `data` شامل `web.config` (برای IIS) و `.htaccess` (برای Apache)؛ فایل وضعیت داخل این پوشه نگهداری و از وب مسدود می‌شود.

آدرس API نهایی:
`https://farshkashanco.com/happguard/guard.php`

**این کلید را عمومی نکن.** چون داخل برنامه اندروید هم ذخیره می‌شود، این یک محافظت کاربردی برای استفاده شخصی است، نه احراز هویت غیرقابل استخراج در برابر مهاجم حرفه‌ای.

## راه‌اندازی
1. در File Manager هاست، در ریشه سایت پوشه `happguard` بساز؛ کنار فایل‌های PHP فعلی سایت.
2. `guard.php` و پوشه `data` را داخل پوشه `happguard/` آپلود کن. فایل‌های حفاظتی داخل `data` هستند؛ فایل `web.config` اصلی سایت را دست نزن و جایگزین نکن.
3. مطمئن شو دامنه HTTPS فعال است.
4. هر دو گوشی باید همین آدرس و همین کلید را در Happ Guard وارد کنند.
5. پوشه باید برای PHP امکان ساخت/نوشتن `guard-state.json` داشته باشد. معمولاً سطح دسترسی پوشه 755 کافی است؛ اگر خطای storage آمد، از پشتیبانی هاست بخواه دسترسی نوشتن PHP را اصلاح کند، نه اینکه مجوز 777 بدهی.

## تست API پس از آپلود
با باز کردن آدرس در مرورگر باید پاسخ `POST only` با کد 405 بگیری؛ این طبیعی است. برای تست کامل باید از داخل برنامه یا درخواست POST با کلید استفاده شود.

## نکته عملکردی مهم
نسخه اندروید فعلی هنوز APK کامپایل‌شده و روی دو گوشی آزمایش‌شده نیست. برنامه از URI اختصاصی `happ://disconnect_without_ui` برای درخواست قطع تونل استفاده می‌کند و در صورت عدم پشتیبانی، روش Accessibility را امتحان می‌کند. عمداً از URI نوع toggle استفاده نشده تا تونل خاموش به اشتباه روشن نشود. گوشی قبلی باید روشن، آنلاین و سرویس Happ Guard آن فعال باشد. قطع موفق باید روی هر دو گوشی عملاً آزمایش شود.
